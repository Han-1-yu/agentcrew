## 1. 输入与目标

输入是用本机 Edge headless 对一个静态登录页截出的真实 PNG（800×600，15,177 字节）：
白色卡片、`AgentCrew 登录` 标题、账号/密码输入框、蓝色登录按钮。

目标原文：

> 根据附带的登录页截图，用单个静态 HTML 文件复刻并改进该页面：保留 AgentCrew
> 登录标题、账号输入框、密码输入框和登录按钮，把按钮从蓝色改为绿色，并增加忘记
> 密码链接。交付 index.html，CSS 内联，无需外部依赖，可直接在浏览器打开。

## 2. 直连探针：key 与视觉模型均可用

`output/_eval/vision/probe_zhipu.py` 直接调用智谱 OpenAI 兼容端点，不经过框架：

- `glm-4v-flash` HTTP 200，能读出标题、账号/密码框与蓝色按钮；
- `glm-4.5v` HTTP 200，`max_tokens=2048` 可用，同样正确识别页面；
- 最终选用 `glm-4.5v`，给 HTML 产物和 reasoning tokens 留出输出预算。

## 3. 两次失败/对照不是「绿证据」，但定位了真实配置边界

| 尝试 | 结果 | 处置 |
| --- | --- | --- |
| 只开 YAML 的 zhipu 视觉能力位 | 实际仍跑 `deepseek-chat`；6 条 `vision_unsupported`，模型没有收到图 | `.env` 的 `AGENTCREW_DEFAULT_MODEL` 优先级高于 YAML；运行时显式设为 `zhipu:glm-4.5v`。这次保留为「盲写对照」，不计入 B2 通过证据 |
| `glm-4v-flash` 首次完整 run | 智谱 HTTP 400：`max_tokens参数非法：限制数值范围[1,1024]`，run failed | 不放宽门禁、不改框架判定；换用 GLM-4.5V，并在 provider override 设 `max_output_tokens: 4096` |

## 5. 可复跑入口

仓库新增 `examples/agentcrew.vision.example.yaml`（无密钥）：

```bash
# 先把 ZHIPU_API_KEY 放进 .env 或环境变量
AGENTCREW_CONFIG=examples/agentcrew.vision.example.yaml \
AGENTCREW_DEFAULT_MODEL=zhipu:glm-4.5v \
python main.py run \
  --goal "根据附带的截图复刻登录页，把按钮改为绿色并增加忘记密码链接，交付 index.html" \
  --image login.png --auto --max-llm-calls 30 --max-cost 0.20
```

Windows PowerShell 用 `$env:AGENTCREW_CONFIG=...` 与
`$env:AGENTCREW_DEFAULT_MODEL="zhipu:glm-4.5v"` 设置同样的两个环境变量。
