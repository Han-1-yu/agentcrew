# ADR-0006：evals 用确定性断言 + pass^k，不用 LLM judge

- **状态**：已接受（2026-11-08）
- **关联**：`evals/`；`examples/evals/smoke.jsonl`；方案 P2「evals」

## 背景

方案把 evals 列为「离线回归 + 真实 smoke + LLM judge」。LLM judge（用模型给模型打分）
把「评测」变成了另一个需要评测的东西，且每次跑都要花钱、结果不可复现。离线回归的
价值恰恰在于确定性、可进 CI、天天跑不花钱。

## 决策

- 离线套件只做**确定性断言**（产物存在/含/不含/正则/行数/事件次数/任务终态）。
- 指标同时报 `pass@1` 与 `pass^k`（k 次全过才算过），波动 case 不被平均掉。
- **不做 LLM judge**；判不动的维度写成人看，不伪装成自动化。
- 真实 smoke 用手工跑 + `--max-cost`/`--max-llm-calls` 兜底，不自动化计费调用。

## 后果

- 得到：0 成本、可复现、进 CI 的回归；「改了提示词/模型，效果变好还是变坏」可测。
- 付出：只覆盖「能不能被规则判定」的维度；开放性质量（文风、洞察力）不在自动化内。
- 重审：出现预算内、可复现的语义评估需求时，作为可选插件，不改变默认断言路线。
