```markdown file=docs/PRD.md
# Todo List Web 应用 PRD

## 1. 背景与目标

个人与小团队在一天中会冒出许多待办事项，记在纸上容易丢、记在聊天窗口里会被淹没。
本项目要交付一个轻量的 Todo List Web 应用：打开浏览器即可记录、完成与清理待办，
数据由服务端统一保存，刷新与换设备后仍然可见。

产品目标：让用户在 3 次点击内完成「记一条待办」或「勾掉一条待办」，
并且不需要注册、不需要安装任何客户端。

## 2. 目标用户

| 用户 | 特征 | 核心诉求 |
|---|---|---|
| 个人用户 | 每天有 3～15 条零散待办 | 快速记录，随时勾掉，列表保持整洁 |
| 小团队协作者 | 需要在同一台演示机上核对任务 | 列表可共享查看，误删后能立刻发现 |
| 验收人 | 需要判断功能是否达标 | 每一步操作都有明确的成功或失败反馈 |

## 3. 核心场景

1. 用户打开首页，看到已有待办列表；列表为空时给出明确引导。
2. 用户输入标题并提交，新待办立即出现在列表顶部。
3. 用户勾选某条待办，该条显示为完成状态，未完成计数同步更新。
4. 用户点击编辑，就地修改标题并保存；输入为空时不允许保存。
5. 用户点击删除，该条从列表消失；删除后列表为空时回到空状态提示。
6. 服务端不可用时，页面顶部出现错误提示，用户可稍后重试而无需刷新页面。

## 4. 功能清单与优先级

| 编号 | 功能 | 优先级 | 说明 |
|---|---|---|---|
| F-01 | 查看待办列表 | 必须 | 进入页面即加载，按最新创建在前排序 |
| F-02 | 新增待办 | 必须 | 标题必填、长度不超过 120 字 |
| F-03 | 完成状态切换 | 必须 | 勾选即标记完成，可再次取消 |
| F-04 | 编辑待办标题 | 必须 | 就地编辑，支持回车保存与 Esc 取消 |
| F-05 | 删除待办 | 必须 | 一次点击即删除，无需二次确认弹窗 |
| F-06 | 空数据与错误提示 | 必须 | 空列表、加载中、请求失败三种状态都有文案 |
| F-07 | 待办描述字段 | 可选 | 可补充详细说明，最多 2000 字 |
| F-08 | 多用户与登录 | 暂不做 | 本期为单实例演示，不引入账号体系 |

## 5. 非功能需求

- 首屏加载：本地环境下 1 秒内可见列表。
- 接口响应：单次增删改查在本地环境 200 毫秒内返回。
- 可用性：桌面与移动浏览器均可操作，表单可键盘完成。
- 数据：本期保存在服务端进程内，重启后清空；持久化留待后续迭代。

## 6. 不在本期范围

账号体系、多人实时协作、提醒与到期时间、按标签分组、离线缓存、数据导出。
```

```markdown file=docs/acceptance.md
# 验收标准

每条标准按「输入 → 行为 → 预期结果」编写，均可由人工操作或自动化用例判定。
编号与 `docs/PRD.md` 的功能清单一一对应。

## AC-01 查看待办列表

- 输入：打开应用首页。
- 行为：页面加载后请求待办列表接口。
- 预期结果：已有待办按创建时间倒序展示；列表为空时显示「还没有待办事项」引导文案。

## AC-02 新增待办

- 输入：在输入框填写标题「写周报」并点击「添加」。
- 行为：前端提交新增请求，后端生成 id 与时间戳。
- 预期结果：新待办出现在列表顶部；输入框清空；标题为空时提交被拒绝并给出提示。

## AC-03 完成状态切换

- 输入：勾选某条待办的复选框。
- 行为：前端提交更新请求，只携带状态字段。
- 预期结果：该条显示为完成样式，未完成计数减一；再次点击可取消完成。

## AC-04 编辑待办标题

- 输入：点击某条待办的「编辑」，把标题改为「写周报（终稿）」后保存。
- 行为：前端提交更新请求，后端返回更新后的实体。
- 预期结果：列表显示新标题；把标题清空后保存会被拒绝，原值保持不变。

## AC-05 删除待办

- 输入：点击某条待办的「删除」。
- 行为：前端提交删除请求。
- 预期结果：该条从列表消失；删除最后一条后回到空状态提示。

## AC-06 错误分支

- 输入：请求不存在的待办 id。
- 行为：后端返回 404 与可读的错误消息。
- 预期结果：前端不崩溃，显示错误提示；接口返回体包含 detail 字段。

## AC-07 输入校验

- 输入：标题超过 120 字，或请求体里带未声明字段。
- 行为：后端在进入业务逻辑前校验请求体。
- 预期结果：返回 422；不产生新的待办记录。

## AC-08 文档与运行方式

- 输入：按 README 的快速开始逐步执行。
- 行为：安装依赖并启动服务。
- 预期结果：服务监听 8000 端口；首页可打开；/docs 可查看接口文档。
```
